SeedPod Status Values

Each seedpod carries a status that reflects how complete and polished it is. From most to least complete:

StatusMeaning
draftComplete; word count checked. Any status beginning with “draft” qualifies.
roughAll four sections present but need a lot of work.
partialTwo or three sections have content.
prelimOne section, complete.
protoOne section, rough.
emptyNo sections yet.
