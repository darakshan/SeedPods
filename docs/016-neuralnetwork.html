A neural network is not analogous to Whitehead’s picture. It is a concrete instance of it.

Proto

A large neural network running on a computer is literally a nested hierarchy of actual processes, electrons, gates, activations, layers, attention heads, the full forward pass, each level making state-transforming decisions that propagate upward and downward.

Each forward pass is an event: it takes in an input, prehends the entire inherited structure of all that training, synthesizes a response through a process that cannot be predicted in detail from outside, and completes into an output. This is the three-beat pattern instantiated at every level of the stack simultaneously. The weight space of the network is the space of pure possibility, the field, from which each forward pass selects a realization1.
